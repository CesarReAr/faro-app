# FARO

F.A.R.O. (Follow-up de Área y Resultados Operativos): seguimiento diario y semanal de las tiendas de un área retail. Una sola página (`index.html`), sin compilación, publicada en GitHub Pages: https://cesarrear.github.io/faro-app/

- Cómo combina los datos: [FUNCIONAMIENTO.md](FUNCIONAMIENTO.md)
- Decisiones y mejoras pendientes: [PENDIENTES.md](PENDIENTES.md)

Los datos viven en Supabase y solo se ven con usuario y permisos de tienda.
